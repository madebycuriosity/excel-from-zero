# Excel From Zero

**An interactive, beginner-first Excel learning platform for people who have never opened a spreadsheet.**

> **Nobody ever showed you the little square.**

Excel is often taught by starting with formulas and functions. For a complete beginner, the real challenge can be much simpler: understanding what a cell is, where to click, what happens when you type, and how a spreadsheet actually behaves.

**Excel From Zero** was created to make those first steps practical, interactive and less intimidating.

## What is it?

Excel From Zero is a hands-on learning environment where learners practise directly in an interactive spreadsheet-style grid rather than simply watching videos.

The platform currently contains:

* **13 parts**
* **52 lessons**
* Interactive spreadsheet practice
* Beginner-to-intermediate Excel concepts
* Real-world data examples
* Project-based activities
* No account required
* No software download required

## Learning Pathway

The course progresses from the absolute basics toward practical spreadsheet analysis and judgement.

### Part 1 — Getting Comfortable

Cells, addresses, typing, editing, undoing, selecting ranges and understanding `#####`.

### Part 2 — Making It Calculate

Formulas, `SUM`, relative references, absolute references and the fill handle.

### Part 3 — What Kind of Data Is This?

Categorical and numerical data, nominal and ordinal data, and interval versus ratio scales.

### Part 4 — Describing Data

Mean, median, outliers, range, standard deviation, quartiles and choosing appropriate summary measures.

### Part 5 — Working With Real Data

Sorting, `COUNTIF`, `SUMIF`, `XLOOKUP` and PivotTables.

### Part 6 — Showing What You Found

Choosing appropriate charts and understanding misleading axes.

### Part 7 — Things That Go Wrong Quietly

Numbers stored as text, dates, disappearing zeros, formatting, Paste Values and incomplete ranges.

### Part 8 — Making Excel Decide

`IF`, `AND`, `OR` and nested `IF` statements.

### Part 9 — Put It Together

Two project-based activities requiring learners to diagnose a spreadsheet and communicate something useful from the data.

### Part 10 — Text, Dates and Errors

`TRIM`, `LEN`, `LEFT`, `MID`, `RIGHT`, `DAY`, `MONTH`, `YEAR` and `IFERROR`.

### Part 11 — Numbers That Mean Something

Percentage change, `ROUND` and `CORREL`.

### Part 12 — The Menu, Not the Formula

Filtering, Remove Duplicates, Find and Replace, Conditional Formatting, Data Validation and Text to Columns.

### Part 13 — The Judgement Calls

Missing values and understanding when the mode is the appropriate measure.

## Design Philosophy

The project is built around a simple principle:

**Learn by doing, not just by watching.**

Each lesson aims to end with a definite capability — something the learner can now do that they could not confidently do before.

The platform is deliberately designed to start at the very beginning rather than assuming prior spreadsheet experience.

## Who Is It For?

The initial target audience is **Australian undergraduate students who are starting from zero with Excel**.

The learning sequence is also suitable for anyone who wants a practical introduction to spreadsheet-based data work.

## Current Technology

The current prototype is built as a lightweight, single-page web application using:

* HTML
* CSS
* JavaScript
* Interactive spreadsheet-style components

The project is currently implemented as a single `index.html` prototype and deployed as a web application.

## Why I Built It

Many Excel resources begin with functions and formulas. This project explores a different approach: **start with the user's first interaction with a spreadsheet and gradually build confidence through practice.**

The project combines educational design, user experience, spreadsheet concepts and interactive web development.
